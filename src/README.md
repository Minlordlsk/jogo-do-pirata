# 🏴‍☠️ Caça ao Tesouro Pirata

## 📌 Sobre o projeto
Jogo desenvolvido em Kotlin no qual o jogador controla um navio pirata e precisa encontrar um tesouro escondido, administrando suas provisões e tripulação.

## ⚙️ Como funciona
O jogo gera um tesouro em coordenadas aleatórias em um mapa de 0 a 20. O jogador pode navegar pelo mapa, consultar pistas e verificar o status do navio. As viagens consomem provisões conforme a distância e as condições climáticas. O objetivo é encontrar o tesouro antes de ficar sem recursos.

## 🛠️ Conceitos utilizados
- Entrada e saída de dados pelo terminal.
- Operadores matemáticos, lógicos e relacionais.
- Condições `if/else` e `when`.
- Laços de repetição `for` e `while`.
- Funções para organizar o código.
- Null Safety para tratar entradas inválidas e valores nulos.

## ▶️ Como executar
1. Abra o projeto no IntelliJ IDEA.
2. Localize o arquivo `Main.kt`.
3. Execute a função `main()` e siga as instruções no terminal.
